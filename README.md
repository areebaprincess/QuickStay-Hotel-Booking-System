# QuickStay Hotel Booking System

A web-based hotel booking system that allows users to search for hotels, book rooms, and manage reservations through an easy-to-use interface. The system is developed using HTML, CSS, JavaScript, Bootstrap, PHP, and MySQL.

---

## 🚀 Overview

QuickStay Hotel Booking System is designed to simplify the hotel reservation process for both customers and administrators. Users can browse available rooms, make bookings, and manage their reservations, while administrators can efficiently manage hotels, rooms, and bookings.

---

## ✨ Features

### User Features
- User Registration and Login
- Search Hotels and Available Rooms
- Room Booking
- Booking Confirmation
- View Booking History
- Responsive User Interface

### Admin Features
- Secure Admin Login
- Manage Hotels
- Manage Rooms
- Manage Users
- View and Manage Bookings
- Update Room Availability

---

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP (Apache & MySQL)

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/QuickStay-Hotel-Booking-System.git
```

### Move the project

Copy the project folder into:

```
xampp/htdocs/
```

### Import the Database

1. Open phpMyAdmin.
2. Create a new database.
3. Import the provided SQL file.

### Start XAMPP

Start:

- Apache
- MySQL

### Run the Project

Open your browser and visit:

```
http://localhost/QuickStay-Hotel-Booking-System/
```
